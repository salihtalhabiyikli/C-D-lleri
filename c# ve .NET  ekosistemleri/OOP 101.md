**OOP (Object Oriented Programming)** = Nesne Tabanlı Programlama
Programlarımızı **nesneler** etrafında kurarız. Her nesne, gerçek dünyadaki bir şeyi temsil eder.

**Örnek:** Bir araba düşünelim.

- Arabanın **özellikleri** vardır: renk, marka, hız
    
- Arabanın **yapabildikleri** vardır: git, dur, hızlan
    

İşte OOP'de bu "özellikler" ve "yapabildikler" bir araya gelerek **sınıf (class)** oluşturur.
## **2. Class (Sınıf) Nedir?**

**Class** = Bir nesnenin şablonu/kalıbıdır.

**Örnek:** Bir "Araba" sınıfı oluşturalım.
```C#
class Araba
{
    // Özellikler (Fields)
    public string renk;
    public string marka;
    public int hiz;
}

```
Class'ın içinde:

- **Field'lar** (Özellikler) → Nesnenin sahip olduğu veriler
    
- **Method'lar** (Davranışlar) → Nesnenin yapabildiği işler
## **3. Nesne (Object) Nedir?**
```C#
// Class (Şablon)
class Ogrenci
{
    // Field'lar (Özellikler)
    public string ad;
    public int yas;
    public string okul;
}

// Program
class Program
{
    static void Main(string[] args)
    {
        // Nesne oluşturma (Kalıptan ürün çıkarma)
        // Sınıf adı nesne adı = new sınıf adı
        Ogrenci ogrenci1 = new Ogrenci();
        ogrenci1.ad = "Ali";
        ogrenci1.yas = 15;
        ogrenci1.okul = "Atatürk Lisesi";
        
        Ogrenci ogrenci2 = new Ogrenci();
        ogrenci2.ad = "Ayşe";
        ogrenci2.yas = 16;
        ogrenci2.okul = "Atatürk Lisesi";
        
        Console.WriteLine(ogrenci1.ad + " - " + ogrenci1.yas + " yaşında");
        Console.WriteLine(ogrenci2.ad + " - " + ogrenci2.yas + " yaşında");
    }
}
```

## **3. Field'lar (Özellikler)**

Field'lar, bir sınıfın **özelliklerini** tutan değişkenlerdir.
```C#
class Kitap
{
    // Field'lar
    public string baslik;
    public string yazar;
    public int sayfaSayisi;
    public double fiyat;
}
```

## **4. Method'lar (Davranışlar)**

Method'lar, bir sınıfın **yapabildiği işlemlerdir**

```C#
class Kitap
{
    public string baslik;
    public string yazar;
    public int sayfaSayisi;
    
    // Method (Davranış)
    public void BilgiYazdir()
    {
        Console.WriteLine("Kitap: " + baslik);
        Console.WriteLine("Yazar: " + yazar);
        Console.WriteLine("Sayfa: " + sayfaSayisi);
    }
    
    // Parametre alan method
    public void IndirimYap(double indirimOrani)
    {
        double yeniFiyat = fiyat - (fiyat * indirimOrani / 100);
        Console.WriteLine("İndirimli fiyat: " + yeniFiyat);
    }
}
```
## **5. Constructor (Yapıcı Method)**

```C#
using System;
class Kitap
{
    public string baslik;
    public string yazar;
    
    // Constructor (Class ile aynı isimde, geri dönüş tipi yok)
    public Kitap(string baslik, string yazar)
    {
        this.başlık = baslik;  // this = bu nesnenin field'ı
        this.yazar1 = yazar;
    }
    static void Main(string[] args)
    { 
    Kitap kitap1=new Kitap("Suc ve Ceza", "Dostoyevski");
    
    Console.WriteLine (kitap1.başlık);
    Console.WriteLine (kitap1.yazar1);
    }
}
```
-  Bu kısımda parametre sayısına dikkat ediniz. 
- This ile tanımladığınız noktalarda [x] x index değeri olmak üzere tek parametredede gönderebilirsiniz. 

- OOP de en çok karışan kısım her olayın nesnenin classın bir sırası olmasıdır.

## **NE NEREDE TANIMLANIR?**

|Şey|Nerede Tanımlanır?|Neden?|
|---|---|---|
|**Field'lar** (marka, model, stok)|**Class'ın içinde**|Bunlar dolaptaki malzemeler, hep orada dururlar|
|**Method'lar** (BilgiGoster, StokAzalt)|**Class'ın içinde**|Bunlar tarifler, dolabın içinde olur|
|**Constructor**|**Class'ın içinde**|Bu da dolabın kurulum kılavuzu|
|**Nesneler** (telefon1, telefon2)|**Main'in içinde**|Bunlar yaptığın yemekler, tezgahta oluşur|
|**Değer atama** (marka="Apple")|**Main'in içinde**|Yemek yaparken malzemeyi kullanırsın|
``` c#
using System;
class Telefon 
{
    public string marka;
    public string model;
    public double fiyat;
    public int stok;
    
    public Telefon( string marka,string model,
    double fiyat,
     int stok)
    {
        this.marka=marka;
        this.model=model;
        this.fiyat=fiyat;
        this.stok= stok;
    }
    
    public void BilgiGoster()
    
    {
        Console.WriteLine(marka);
        Console.WriteLine(model);
        Console.WriteLine(fiyat);
        Console.WriteLine(stok);
    }
    
    public void StokAzalt(int adet)
    {
        if (stok >= adet)
        {
            stok = stok - adet;
            Console.WriteLine(adet + " adet " + model + " satıldı.");
            Console.WriteLine("Kalan stok: " + stok);
        }
        else
        {
            Console.WriteLine("Yeterli stok yok! Mevcut stok: " + stok);
        }
    }
    
    static void Main(string[] args)
    {
        // Telefon nesneleri oluştur
        Telefon telefon1 = new Telefon("Apple", "iPhone 14", 45000, 10);
        Telefon telefon2 = new Telefon("Samsung", "Galaxy S23", 38000, 5);
        
        // Bilgileri göster
        Console.WriteLine("--- TELEFON 1 ---");
        telefon1.BilgiGoster();
        
        Console.WriteLine("\n--- TELEFON 2 ---");
        telefon2.BilgiGoster();
        
        // Stok azaltma işlemi
        Console.WriteLine("\n--- STOK GÜNCELLEME ---");
        telefon2.StokAzalt(3);
    }
}

```

### Erişim Belirleyicileri Tablosu

| **Anahtar Kelime**       | **Açıklama**               | **Kapsam**                                                                      |
| ------------------------ | -------------------------- | ------------------------------------------------------------------------------- |
| **`public`**             | Sınır yok.                 | Her yerden erişilebilir.                                                        |
| **`internal`**           | Aynı proje (Assembly) içi. | Sadece bulunduğu projenin içinden erişilebilir.                                 |
| **`protected internal`** | Proje içi veya Miras.      | Aynı projeden **veya** başka projedeki alt sınıflardan erişilebilir.            |
| **`protected`**          | Miras (Inheritance).       | Sadece tanımlandığı sınıftan veya o sınıfı miras alan sınıflardan erişilebilir. |
| **`private protected`**  | Aynı proje + Miras.        | Sadece aynı projede olan **ve** miras alan sınıflardan erişilebilir.            |
| **`private`**            | En kısıtlı.                | Sadece tanımlandığı sınıf (`class`) veya yapı (`struct`) içinden erişilebilir.  |
